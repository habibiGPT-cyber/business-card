# Cardly public profile

This is a static GitHub Pages site. Edit the `profile` object in `profile.js`, publish this folder (or its contents) to a GitHub repository, then copy the GitHub Pages URL into Cardly's **Public Link** field. The QR code and physical NFC tag will then open this profile immediately. `profile.png` is the portrait asset used in the hero card.

Enable Pages in GitHub under **Settings → Pages → Deploy from a branch**, select `main` and `/ (root)`. Use HTTPS and a custom domain for production.
